# Security Policy

Report vulnerabilities privately to the repository owner. Do not include credentials, tenant data, exploit payloads, or live target details in a public issue.

The conformance kit accepts local, digest-bound inputs only. Live execution is unavailable unless an independently installed root-owned launcher validates two envelope signatures, an independent capacity signature, exact endpoints, admission policy, quota, and OS isolation before repository code runs.

No production secret or private signing key belongs in this repository.
